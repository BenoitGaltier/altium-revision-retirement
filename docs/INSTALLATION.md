# Altium Revision Retirement — compiled Windows release

This package contains the compiled extension. Installation does not run a compiler, MSBuild, a source project or an EPD file.

Version 0.1.6 is a preview prepared for native acceptance testing. Preparing or downloading the package does not install it. Version 0.1.5 remains the latest non-preview release.

The runtime bundle is intended for authorized internal Fluidra use and is hosted in a private GitHub release repository. Download access follows that repository's permissions.

## Requirements

- Windows x64 with .NET Framework 4.8 and 64-bit Windows PowerShell 5.1 or PowerShell 7.
- Altium Designer. The extension was built and tested with Designer 26.11.1.28.
- The package includes `Altium.SDK.dll` and `Altium.SDK.Interfaces.dll`. No Altium Developer installation, SDK, IDE, compiler or SDK ticket is needed on the target PC.

The installer verifies every bundled file against `manifest.json` and copies the two runtime libraries only into this extension's own folder. Existing Altium system libraries and other SDK installations are not replaced. See `THIRD_PARTY_NOTICES.md` for vendor copyright and license information. SDK sources, tickets and activation credentials are excluded.

## Install

1. Download **`altium-revision-retirement-0.1.6-windows-x64.zip`** from its [private GitHub release](https://github.com/BenoitGaltier/altium-revision-retirement-fluidra-releases/releases). Choose this asset for installation. GitHub's automatic **Source code** archives are for development.
2. Extract the complete ZIP. Close Altium Designer normally and handle your own unsaved documents.
3. Open a 64-bit PowerShell window in the extracted folder and run:

   ```powershell
   .\Install.ps1
   ```

4. If Windows denies access to Altium's ProgramData directory, rerun PowerShell as administrator. The installer does not elevate itself or close Altium.
5. Restart Designer and open **Tools → Revision Retirement…** in a schematic or PCB editor.

If Windows shows a downloaded-script security warning, verify that the ZIP came from the repository above. Use the ZIP file's **Properties → Unblock** before extracting it again, or unblock only the two extracted installer scripts:

```powershell
Unblock-File -LiteralPath .\Install.ps1
Unblock-File -LiteralPath .\scripts\install.ps1
```

This does not change your machine's execution policy.

## Check dependencies without installing

```powershell
.\Install.ps1 -CheckOnly
```

This checks the complete package, selected Altium installation, bundled runtime libraries and .NET Framework prerequisite. It writes no files or registrations and can run while Designer is open.

By default, the newest installed Designer instance is selected. Use `-AltiumApplication` with the installation's `Application` registry value, or `-AltiumExtensionsPath` with its existing `Extensions` directory, to select another instance. The selected version and destination are printed before installation.

## What is installed

The installer validates the packaged extension DLL, native INS/RCS resources, Fluidra icons, English guide, third-party notices and both bundled Altium runtime DLLs, then copies them into `Extensions\AltiumRevisionRetirement`. It creates or updates only this extension's entry in `ExtensionsRegistry.xml`, using the native registration structure generated by Altium Developer. Other extension entries are checked for preservation.

Existing managed files and the registry are backed up under `%LOCALAPPDATA%\AltiumRevisionRetirement\InstallationBackups`. Each successful installation has an `installed-files.json` hash receipt. An interrupted file deployment before registry replacement attempts to restore the previous managed files.

Installation does not connect to an Altium 365 workspace or change component data or lifecycle states. See the installed `USER_GUIDE.en.md` or the [online English guide](https://github.com/BenoitGaltier/altium-revision-retirement/blob/main/docs/USER_GUIDE.md) before using the extension.
